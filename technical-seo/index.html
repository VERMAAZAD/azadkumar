What technical SEO actually covers

Technical SEO is everything that affects how search engines access and understand your pages, apart from the content itself. A well-written page still fails if it is blocked by robots.txt, buried deep in the site, slow on mobile or duplicated across several URLs. Fixing these problems removes the ceiling on every other SEO effort.

Crawlability

Making sure bots can reach important pages through clean internal links, sensible robots.txt rules and no crawl traps.

Indexing

Checking what Google and Bing have indexed, removing thin or duplicate pages and fixing “Discovered, not indexed” problems.

XML sitemaps

Clean sitemaps that list only canonical, indexable URLs and are submitted in Search Console and Bing Webmaster Tools.

Canonicals and redirects

One preferred URL per page, correct 301 redirects and no chains or loops that waste crawl budget.

Site architecture

A logical hierarchy and internal linking so authority flows to key pages and visitors never get lost.

Schema markup

Structured data such as Organization, Article, FAQ and Product so search engines understand your content.

Mobile and security

Mobile-friendly layouts, HTTPS everywhere and no mixed-content warnings.

Errors and broken links

Finding 404s, soft 404s and server errors before they cost you visibility.

Core Web Vitals and page speed

Google uses real-user data to judge page experience. The three Core Web Vitals are Largest Contentful Paint (how fast the main content appears), Interaction to Next Paint (how quickly the page responds) and Cumulative Layout Shift (how stable the layout is). I test with PageSpeed Insights, GTmetrix and Search Console, then fix the causes instead of chasing scores.

  • Compress and correctly size images, use modern formats and lazy-load media below the fold
  • Remove render-blocking CSS and JavaScript and defer what is not needed immediately
  • Set width and height on images and embeds to prevent layout shifts
  • Improve server response with better hosting, caching and a CDN where it helps
  • Cut unused third-party scripts that slow down interaction

My technical SEO process

  1. Crawl and collect

    I crawl the site with Screaming Frog and combine the data with Search Console, Bing Webmaster Tools and GA4.

  2. Diagnose

    Every issue is grouped by type and judged by impact, so one important fix is never buried under 200 minor warnings.

  3. Prioritize

    You get a roadmap sorted by impact and effort, with the reason behind each recommendation.

  4. Implement

    Where I have access I make the fixes myself; otherwise I give your developer exact, copy-ready instructions.

  5. Verify and monitor

    I re-crawl, request re-indexing for fixed pages and track results over the following weeks.

Problems I commonly find

  • Important pages accidentally set to noindex or blocked in robots.txt
  • Duplicate content from www and non-www, HTTP and HTTPS, or URL parameters
  • Sitemaps that include redirected, broken or non-canonical URLs
  • Orphan pages with no internal links pointing to them
  • Missing or invalid schema markup
  • Slow mobile pages caused by oversized images and heavy scripts
  • Site migrations that dropped redirects and lost rankings

Frequently asked questions

How long does a technical SEO audit take?

It depends on the size and complexity of the site. A small business site can usually be audited in a few days, while large or e-commerce sites take longer. You receive a prioritized report, not a data dump.

Can technical SEO alone improve my rankings?

It removes obstacles so well-written pages can rank as they deserve. It works best together with strong content and quality links, and nobody can honestly guarantee a specific position.

Do you fix the issues or only report them?

Both. I can implement fixes on your site if I have access, or hand a clear task list to your developer.

Do you optimize for Bing as well as Google?

Yes. I set up Bing Webmaster Tools, submit sitemaps there and check indexing on both engines, since Bing also feeds Microsoft Copilot and other search products.
